Step 1 of 5

The skeleton

lib/main.dartLoginPage · build()
return Scaffold(
  body: SafeArea(
    child: SingleChildScrollView(
      padding: const EdgeInsets.all(24),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.stretch,
        children: [
          // our widgets go here
        ],
      ),
    ),
  ),
);
SafeAreaKeeps content away from the notch and status bar
SingleChildScrollViewLets the page scroll, so the keyboard never causes an overflow
.stretchEvery child is full width, so buttons and fields too
Make LoginPage its own StatelessWidget, and put it in home: of MaterialApp.

Bonus widget

GestureDetector: make anything tappable

lib/main.dart
GestureDetector(
  onTap: () {
    print('Logo tapped!');
  },
  child: const FlutterLogo(size: 80),
),

Buttons already react to taps. GestureDetector adds taps to any widget: a logo, a card, a picture.

onTapOne quick tap
onDoubleTapTwo quick taps
onLongPressPress and hold
Mobile App Development · Lecture 08

Use a real button when the thing looks like a button. Use GestureDetector for cards, pictures and other non-button things.

Quality check

Before you call a screen "done"

It works

  • No red errors or yellow-black stripes
  • Open the keyboard: the page still scrolls
  • Every button does something (even a SnackBar)
  • Tested on a small phone or emulator

It looks good

  • The same space everywhere (8, 16, 24…)
  • All fields use the same style
  • Nothing touches the screen edges
  • Two or three colors, used the same way

Step 3 · Customize

Parameters: give the widget its data

lib/main.dartInfoCard
class InfoCard extends StatelessWidget {
  const InfoCard({
    super.key,
    required this.icon,
    required this.text,
  });

  final IconData icon;
  final String text;

  @override
  Widget build(BuildContext context) {
    return Container(
      // … same padding and decoration …
      child: Row(children: [
        Icon(icon, color: Colors.blue),
        const SizedBox(width: 12),
        Text(text),
      ]),
    );
  }
}
1Constructor: ask for the datarequired = you must give it. this.icon = save it in the field.
2Fields: keep the datafinal = set once, never changes. IconData is the type of Icons.email.
3build(): use the dataUse icon and text like normal variables.
Remove const from the Row: its icon and text are different every time.
Mobile App Development · Lecture 08

Read the class top to bottom: the constructor asks for the data, the fields keep it, build() uses it. The { } in the constructor make these named parameters, so we write icon: and text: when we use it.

Parameters can be functions

A reusable button: pass a function

lib/main.dartAppButton
class AppButton extends StatelessWidget {
  const AppButton({
    super.key,
    required this.text,
    required this.onPressed,
  });

  final String text;
  final VoidCallback onPressed;

  @override
  Widget build(BuildContext context) {
    return SizedBox(
      height: 50,
      child: ElevatedButton(
        onPressed: onPressed,
        child: Text(text),
      ),
    );
  }
}
VoidCallbackThe type of a function like () { }: no inputs, gives nothing back
onPressed: onPressedThe button runs your function
using it
AppButton(

    print('Saved!');
  },
),
Same idea as lecture 7: "when this happens, run this". Your widget takes the function and hands it to the button.

Watch out

Common mistakes and how to fix them

The error says…The fix
The named parameter 'text' is required, but there's no corresponding argument.You forgot a value. Give it: InfoCard(icon: …, text: '…')
Too many positional arguments: 0 expected, but 2 found.Write the names: icon: Icons.email, not just Icons.email
The parameter 'text' can't have a value of 'null' because of its type…Add required before this.text, or give it a default value
The method 'InfoCard' isn't defined…The file is not imported. Add import 'widgets/info_card.dart';
Can't define a const constructor for a class with non-final fields.Make every field final

The login page, the reusable way

class AppTextField extends StatelessWidget {
  const AppTextField({
    super.key,
    required this.label,
    required this.icon,
    this.isPassword = false,
  });

  final String label;
  final IconData icon;
  final bool isPassword;

  @override
  Widget build(BuildContext context) {
    return TextField(
      obscureText: isPassword,
      decoration: InputDecoration(
        labelText: label,
        prefixIcon: Icon(icon),
        border: const OutlineInputBorder(),
      ),
    );
  }
}

Quality check

Before you call a screen "done"

It works

  • No red errors or yellow-black stripes
  • Open the keyboard: the page still scrolls
  • Every button does something (even a SnackBar)
  • Tested on a small phone or emulator

It looks good

  • The same space everywhere (8, 16, 24…)
  • All fields use the same style
  • Nothing touches the screen edges
  • Two or three colors, used the same way

The code is clean

  • No copy-paste: repeated parts are one custom widget
  • What changes is a parameter
  • Each widget in its own file
  • Clear names: InfoCard, not Widget1
Mobile App Development · Lecture 08

This is also how projects are graded: does it work, and does it look clean? The third card is today's lesson: clean code is easier to change later.

You already wrote two: MyApp and LoginPage! A custom widget is a class that builds other widgets.

Step 1 · Extract

Move the TextField into its own class

lib/main.dartat the bottom
class AppTextField extends StatelessWidget {
  const AppTextField({super.key});

  @override
  Widget build(BuildContext context) {
    return const TextField(
      decoration: InputDecoration(
        labelText: 'Email',
        prefixIcon: Icon(Icons.email),
        border: OutlineInputBorder(),
      ),
    );
  }
}

Step 2 · Parameters

Give the widget its data

lib/main.dartAppTextField
class AppTextField extends StatelessWidget {
  const AppTextField({
    super.key,
    required this.label,
    required this.icon,
    this.isPassword = false,
  });

  final String label;
  final IconData icon;
  final bool isPassword;

  @override
  Widget build(BuildContext context) {
    return TextField(
      obscureText: isPassword,
      decoration: InputDecoration(
        labelText: label,
        prefixIcon: Icon(icon),
        border: const OutlineInputBorder(),
      ),
    );
  }
}
1Constructor: ask for the datarequired = you must give it. = false = a default, used when you leave it out.
2Fields: keep the datafinal = set once, never changes. IconData is the type of Icons.email.
3build(): use the dataUse label, icon and isPassword like normal variables.
Remove const from TextField: its label and icon are different every time.
Mobile App Development · Lecture 08

Read the class top to bottom: the constructor asks for the data, the fields keep it, build() uses it. The { } make these named parameters, so we write label: and icon: when we use it. isPassword is optional: most fields are not passwords.

Step 4 · A reusable button

AppButton: pass a function

lib/main.dartAppButton
class AppButton extends StatelessWidget {
  const AppButton({
    super.key,
    required this.text,
    required this.onPressed,
  });

  final String text;
  final VoidCallback onPressed;

  @override
  Widget build(BuildContext context) {
    return SizedBox(
      height: 50,
      child: ElevatedButton(
        onPressed: onPressed,
        child: Text(text),
      ),
    );
  }
}
VoidCallbackThe type of a function like () { }: no inputs, gives nothing back
onPressed: onPressedThe button runs your function
using it
AppButton(
  text: 'Login',
  onPressed: () {
    ScaffoldMessenger.of(context).showSnackBar(
      const SnackBar(content: Text('Logging in…')),
    );
  },
),
showSnackBar shows a short message at the bottom for a few seconds.
Mobile App Development · Lecture 08

Same idea as lecture 7: "when this happens, run this". Your widget takes the function and hands it to the ElevatedButton. Each AppButton can do something different (Login, Sign up, Save) but they all look the same. context comes from build(BuildContext context).

Watch out

Common mistakes and how to fix them

The error says…The fix
The named parameter 'label' is required, but there's no corresponding argument.You forgot a value. Give it: AppTextField(label: '…', icon: …)
Too many positional arguments: 0 expected, but 2 found.Write the names: label: 'Email', not just 'Email'
The method 'AppTextField' isn't defined…The file is not imported. Add import 'widgets/app_text_field.dart';
Can't define a const constructor for a class with non-final fields.Make every field final
Bottom overflowed by … pixels.The keyboard covers the page. Wrap the Column in SingleChildScrollView

Show one or two of these live: delete required, or forget a parameter, and read the red message together. Error messages tell you the fix if you read them slowly.
